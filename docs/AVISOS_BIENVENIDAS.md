# Avisos de bienvenidas pendientes

El dashboard del administrador central FINSER y del analista, y la revisión por enlace vigente, incluyen un aviso compacto para la bandeja de Aprobaciones. No crea una bandeja de bienvenida distinta.

- Se consulta un resumen privado cada 30 segundos y al regresar a la ventana o recuperar conexión. No se envían nombres, cédulas, valores ni documentos al componente de avisos.
- Los pendientes por gestionar excluyen las solicitudes que esperan exclusivamente respuesta del aliado y las que tienen una reemisión de firma en curso. Las respuestas recibidas vuelven a requerir atención.
- El aviso aparece al detectar trabajo pendiente o un cambio de expedientes, aunque la cantidad sea la misma. Si sigue pendiente, el recordatorio se espacia a diez minutos; los cambios no producen sonidos con menos de un minuto entre avisos.
- `Activar sonido` habilita una señal breve desde una interacción del usuario. La preferencia se conserva por cuenta en ese navegador y puede silenciarse. Si el navegador bloquea el audio, el aviso visual sigue disponible.
- Las pestañas de una misma cuenta coordinan sus avisos para evitar señales repetidas. Al perder autorización se oculta el aviso y se detiene la consulta.

Los avisos funcionan mientras FINSER PAY está abierto. No son Web Push para un navegador cerrado. El navegador puede espaciar temporizadores en pestañas en segundo plano.
